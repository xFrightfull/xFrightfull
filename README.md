## `05` &nbsp; Development Philosophy

<div align="center">

```
  "The best interface is one the user never has to think about."
```

</div>

Three principles I build by:

**→ Intentionality over velocity**
Every decision — from component naming to layout rhythm — is made on purpose. Rushed code creates technical debt. Rushed design creates user friction. I'd rather slow down and build something right.

**→ Depth over breadth**
I'm not trying to know every framework. I'm trying to deeply understand how the web works — and then use the right tools to express that understanding.

**→ Shipped > Perfect**
I believe in iteration. CubeNest is live today not because it's perfect, but because real users teach you things no amount of planning can.
